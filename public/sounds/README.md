# Custom Audio FX Folder

Drop your own sound files (`.mp3`, `.wav`, `.ogg`, `.m4a`) here to replace any procedural gesture or motion sound with your own custom audio!

### Supported File Names:
- `Gun.mp3` (or `gun.mp3`) - Finger Gun action
- `Fist.mp3` (or `fist.mp3`) - Fist / punch action
- `Pinch.mp3` (or `pinch.mp3`) - Pinch action
- `ThumbsUp.mp3` (or `thumbsup.mp3`) - Thumbs Up action
- `ThumbsDown.mp3` (or `thumbsdown.mp3`) - Thumbs Down action
- `Peace.mp3` (or `peace.mp3`) - Peace / Victory action
- `RockOn.mp3` (or `rockon.mp3`) - Rock On action
- `Pointing.mp3` (or `pointing.mp3`) - Pointing action
- `OpenPalm.mp3` (or `openpalm.mp3`) - Open Palm action
- `OK.mp3` (or `ok.mp3`) - OK sign action
- `CallMe.mp3` (or `callme.mp3`) - Call Me / Shaka action
- `Whoosh.mp3` (or `whoosh.mp3`) - Fast hand swipe / air slash action

*You can also upload custom sound files directly from the UI in the Sound FX Engine panel without touching files!*
